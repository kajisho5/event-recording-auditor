# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's
built-in reporting flow, not as a public issue:

1. Go to this repository's **Security** tab.
2. Select **Advisories** → **Report a vulnerability**.

This opens a private advisory visible only to the maintainers until a fix
is ready, and lets you attach details, proof-of-concept code, and
affected versions directly.

## Supported versions

This project is currently in beta (see the README). Security fixes are
only tracked against the latest released version -- there is no separate
long-term-support branch.
